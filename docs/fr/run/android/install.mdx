Ajoutez le SDK GenieX à un projet Android Studio pour que votre application puisse télécharger les poids depuis Hugging Face / Qualcomm AI Hub et les exécuter sur le NPU Hexagon, le GPU Adreno ou le CPU - le tout en Kotlin.

## **Essayer l'application d'exemple d'abord**

Observez GenieX fonctionner sur Android avant d'écrire la moindre ligne de code. L'application de chat de référence avec sélecteur de modèles, reprises de téléchargement et prise en charge VLM - se trouve dans `qualcomm/ai-hub-apps`. Clonez-la, ouvrez-la dans Android Studio et cliquez sur **Run ▶**.

<Card title="Obtenir l'application d'exemple GenieX Chat" icon="github" href="https://github.com/qualcomm/ai-hub-apps/blob/release/geniex_chat_android/README.md">
  Compilez l'application de discussion de référence à partir des sources. Suivez le README pour la cloner, la compiler et la lancer.
</Card>

Sélectionnez un modèle dans le menu déroulant et choisissez NPU, GPU ou CPU au chargement. Appuyez sur le bouton d'image pour les VLM. Restez connecté en Wi-Fi pour le premier téléchargement.

Pas de téléphone disponible ? Voir [Tester sans appareil physique](/fr/resources/faq#how-do-i-test-the-android-demo-without-a-physical-device).

## **Prérequis**

- **Android Studio** [Hedgehog (2023.1.1)](https://developer.android.com/studio/releases/past-releases/as-hedgehog-release-notes) ou plus récent.
- **`minSdk = 27`** (Android 8.1) dans votre module d'application.
- Un smartphone équipé d'un processeur **Snapdragon 8 Elite** (`SM8750`) ou **Snapdragon 8 Elite Gen 5** (`SM8850`) - voir [Plateformes prises en charge](/fr/get-started/platforms).

## **Ajouter le SDK à votre application**

<Steps>
  <Step title="Activer Maven Central">
    Dans votre fichier `settings.gradle.kts` (ou `build.gradle.kts` racine pour les projets plus anciens) :

    ```kotlin
    dependencyResolutionManagement {
        repositories {
            google()
            mavenCentral()
        }
    }
    ```
  </Step>

  <Step title="Ajouter la dépendance">
    Dans le fichier `build.gradle.kts` de votre **module d'application** :

    ```kotlin
    dependencies {
        implementation("com.qualcomm.qti:geniex-android:0.10.0")
    }
    ```

    L'artefact intègre les bibliothèques natives `arm64-v8a` - aucun NDK ni CMake requis de votre côté.
  </Step>

  <Step title="Déclarer les autorisations">
    Le SDK télécharge les poids lors de l'exécution. Dans `AndroidManifest.xml` :

    ```xml
    <uses-permission android:name="android.permission.INTERNET" />
    ```

    Pour les VLM chargeant des images depuis la galerie, déclarez également `READ_EXTERNAL_STORAGE` (ou les autorisations de médias délimitées sur Android 13+).
  </Step>

  <Step title="Synchroniser Gradle">
    Cliquez sur **Sync Now** dans Android Studio.
  </Step>
</Steps>

Rendez-vous ensuite sur le [Démarrage rapide](/fr/run/android/quickstart) pour télécharger et exécuter votre premier modèle.
